# VTA visual direction

## Reference

This project is a faithful rebuild of **VTA — Vector Trade & Analytics** from the approved master brief. It is not a generic fintech redesign. The brief is the current ground-truth reference until the missing `VTA_MASTER_SPEC.md` and original brand assets are supplied.

## Design movement

**Institutional vector intelligence.** A composed, dark financial operating environment where information feels precise, quiet and inspectable. It should feel like a premium global multi-asset control surface—not a casino, meme-coin product, loud neon terminal, or generic AI dashboard.

## Core principles

1. **Truth is a visual feature.** Connected, unavailable, preview, historical and inactive states are explicitly differentiated.
2. **Calm hierarchy.** Large editorial headings, controlled spacing, compact technical labels, and very limited accent color.
3. **Operational confidence.** Fine rules, soft glass panels, deliberate empty states, and quiet status indicators create credible structure without pretending live operations exist.
4. **One visual language.** Public pages, Portal, Terminal and Admin share tokens and primitives while keeping their own density and hierarchy.

## Color philosophy

- Foundation: `#08151A` / `#081417`
- Deep panels: `#102126` / `#122A2E`
- Primary text: `#EDF4F1`
- Muted text: `#96AAA5` / `#6F8881`
- Signal emerald: `#35D3A1` / `#19B985`
- Caution amber: `#EFC171`
- Risk red: `#E58383`
- Borders: muted off-white/emerald at 11–20% opacity

Accents appear in status dots, data lines, focus states and decisive CTAs—not as indiscriminate glow.

## Layout paradigm

Public pages combine a restrained editorial grid with technical dashboard surfaces. The homepage has a large text-led hero alongside a visual “vector globe,” followed by generous product panels and a six-area ecosystem. The Portal uses a 244px desktop sidebar and intent-led empty states. Admin is more dense but retains legible row height, table controls, and generous action targets. On mobile, layouts collapse deliberately into stacked modules and slide-in navigation.

## Signature elements

- A VTA monogram made from a diagonal vector and measured axis marks.
- Soft mint signal lines and circles over a charcoal globe grid.
- Hairline borders and elevated translucent surfaces.
- Compact monospace metadata with uppercase letter spacing.
- High-quality empty states that present the next legitimate connection or activation step.

## Interaction philosophy

Interactions are direct, quiet and reversible. Hover states lift surfaces minimally; keyboard focus uses an accessible mint outline; buttons are clearly primary, secondary or ghost. No flashing price ticks, artificial success confirmations, or simulated trading activity. Motion is subtle and disabled for reduced-motion preferences.

## Typography system

- **Headings / brand:** Manrope, with a compact but not aggressive tracking treatment.
- **Body/UI:** DM Sans, clear and open at regular readable sizes.
- **Technical metadata:** `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`.

## Brand essence and voice

**Precision for every market decision.** VTA is globally aware, transparent about system state, and concise without being cold. The language uses “available,” “connected,” “unavailable,” “historical reference,” and “awaiting configuration” rather than invented market claims.

## Brand mark

No historic logo file is currently available. Use a reconstructed VTA monogram: three broad filled vector/axis forms in emerald and off-white with intentional negative space. It is an original reconstruction for this build, not a claim that it is the prior supplied identity.

## Visual asset plan

The homepage globe uses NASA Earth Observatory’s **Earth at Night / Black Marble** flat-map imagery as a subdued texture under VTA’s original CSS/SVG grid, orbit and data-vector layers. Source: https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/ . It is used only as an atmospheric geographic reference with a visible source note; all VTA overlays and UI are original.
