VTA Platform · Phase 1

Home page changes report

Repo Hackersincome/-vta-platform · Branch v0/header-auth-robot-integration

1What changed

  • Header: “Client Area” replaced with Sign In (/login). “Open portal” button renamed to Sign Up (/register). The mobile menu uses the same two actions.
  • Sign In now stays visible at 821–1050px widths (it was hidden there before).
  • Momentum Booster robot: the boxed photo was replaced with the existing transparent cutout of the same character, with a soft blue/gold glow and a fade into the section at the bottom and right edges.
  • On mobile, the “VTA AUTOMATION / ADVANCED V1” label no longer overlaps the robot.

2Files modified

  • src/App.tsx — header and mobile navigation labels only (5 lines changed).
  • src/styles.css — one scoped block appended at the end (+68 lines) for the header and robot section.
  • No database, server, config, or integration files were changed. No assets were deleted.

3What was verified

  • Home page checked in the browser at 414px (mobile), 900px, and 1440px, dark mode.
  • Sign In goes to /login and Sign Up goes to /register on desktop and in the mobile menu.
  • The robot keeps its look and blends into the section on mobile and desktop.
  • Type check (tsc --noEmit) passes. Other routes were not touched.

4Authentication and robot limitations

  • The real sign-in (/auth/login) depends on the Manus OAuth variables MANUS_OAUTH_PORTAL_URL, MANUS_PROJECT_ID, MANUS_OAUTH_API_URL and a session secret. Without them it returns 503 identity_not_configured.
  • There is no separate registration backend. Sign In and Sign Up both end up at the same external identity provider.
  • A very faint rectangular edge is still visible next to the robot on desktop, caused by older section styles.
  • The footer still says “Client Area” (only the header was in scope).

5Architectural gaps for later phases

  • No database. Deposit/withdrawal transactions are demo data saved in the browser (localStorage).
  • No trading backend. The only API is /api/market/klines (chart data). No MT4/MT5 bridge, accounts, wallets, or balances API.
  • Momentum Booster is interface-only: demo-only mode is enforced, the license is unconfigured, and no trading account is linked.
  • Admin / CRM (/admin/*) has screens but no backend data or role-based authorization.
  • No IB, referral, or affiliate module was found.
  • No real payment provider for deposits and withdrawals; the funding flow uses sandbox outcomes.
